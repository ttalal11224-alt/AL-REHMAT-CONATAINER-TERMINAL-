# Al Rehmat Container Terminal 🚛

A complete, mobile-friendly business website for **Al Rehmat Container Terminal** – Pakistan's trusted provider of container rental, sales, transport and custom modifications.

## 🌐 Pages

| File | Description |
|------|-------------|
| `index.html` | Homepage – hero, services overview, why-us, testimonials, CTA |
| `services.html` | Services – rental, sales, transport, custom modification |
| `solutions.html` | Container Uses & Solutions – 20+ creative business/personal/industrial uses |
| `gallery.html` | Gallery – project photos, before/after, filterable |
| `about.html` | About Us – company story, values, timeline, team |
| `contact.html` | Contact – quote form, WhatsApp integration, FAQ |

## 📁 Project Structure

```
/

└── images/              # Place your container images here
```

## 🚀 Getting Started

Open `index.html` in any web browser – no build step required. The site uses plain HTML, CSS and JavaScript.
